# Example: open-ended area tracking

Illustrative user brief—not a preconfigured integration:

> Follow practical advances in battery recycling: new processes, research with credible performance data, commercial deployments, and consequential policy. Search broadly; don't limit yourself to a fixed list of publishers. Skip routine funding announcements without technical or operational substance. Give me concise sourced updates at 08:00 and 18:00 America/New_York, in my chosen chat. Stay silent if there is nothing worthwhile.

This is **one research task with two editions**, sharing history. The agent confirms the exact destination, schedule semantics, initial window, and dependencies before activation. If the host requires two jobs, both map to this single task.

Evening coverage should focus on new developments since prior successful coverage, with overlap for delayed discovery. It should not repeat the morning's facts merely because another outlet published them.

Pausing this task pauses both schedules. Changing the evening time does not alter the morning edition.
